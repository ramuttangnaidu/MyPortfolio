# Nakka Ram Uttang Naidu - Personal Portfolio

A modern, highly interactive personal portfolio built for my profile as a Backend AI Engineer. Features a cinematic dark-mode design, glassmorphic UI elements, and a fully functional AI chat assistant powered by Claude.

🔗 **[View Live Portfolio](https://my-portfolio-wine-nine-koxms2wtge.vercel.app/)**

---

## ⚡ Tech Stack

- **Framework:** Next.js 16 (App Router)
- **Language:** TypeScript
- **Styling:** Tailwind CSS v4
- **Animations:** Framer Motion
- **AI Integration:** Anthropic API (Claude 3.5 Sonnet)
- **Deployment:** Vercel

## ✨ Features

- **Cinematic Hero Section:** Two-column layout with a glowing, rotating profile card.
- **AI Chat Assistant:** A floating chat widget connected to Claude API, instructed with my resume details to answer visitor questions on my behalf.
- **Glassmorphism UI:** Frosted glass effects on cards and navigation for a premium feel.
- **Interactive Projects:** Hover effects and categorized skills filtering.
- **Responsive Design:** Optimized for mobile, tablet, and desktop viewing.

## 🚀 Quick Start (Local Development)

1. **Clone the repository**
   ```bash
   git clone https://github.com/ramuttangnaidu/MyPortfolio.git
   cd MyPortfolio
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

3. **Set up Environment Variables**
   Create a `.env.local` file in the root directory and add your Anthropic API key (required for the chat widget):
   ```env
   ANTHROPIC_API_KEY=your_api_key_here
   ```

4. **Run the development server**
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser.
